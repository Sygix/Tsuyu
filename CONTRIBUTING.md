# Contributing to Tsuyu

Thanks for your interest in Tsuyu.

## How to contribute

Contributions go through issues and discussions:

- **Bug reports and feature requests:** use [the issue forms](https://github.com/Sygix/Tsuyu/issues/new/choose). Please search the existing issues first.
- **Questions and ideas to discuss:** use [GitHub Discussions](https://github.com/Sygix/Tsuyu/discussions).
- **Security problems:** report them privately, see [SECURITY.md](SECURITY.md).

Never include personal data such as IP addresses, serial numbers, account names, server URLs or tokens in an issue, a discussion or a log excerpt.

## Pull requests

Pull requests are reserved for the repository collaborators. Pull requests from outside contributors are not reviewed or merged, so please do not send patches: open an issue or a discussion describing the problem or the idea instead.
